# SimpleNBTParser

As the name says, it is a simple, single-file NBT parser.

The parser was implemented based on the information found on https://github.com/Querz/NBT and https://minecraft.fandom.com/wiki/NBT_format#Binary_format. 
I created this parser because I wanted a lightweight parser that I could just drop in and modify for each project instead of importing a large library.
